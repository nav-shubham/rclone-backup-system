# Rclone Auto Backup System

## Features
- Multi-folder sync to Google Drive
- Parallel execution
- Logging system
- Retry mechanism

## Setup

1. Install rclone
2. Configure Google Drive:
   rclone config

3. Set path (optional):
   set RCLONE_PATH=path_to_rclone.exe

4. Run:
   python gdrive_sync_master.py
